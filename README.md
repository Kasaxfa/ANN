## Методика

По заданию «Кодировка категорий» базовая сеть обучается **без категориальных столбцов**.
Числовые входы: `Age`, `Weight (kg)`, `Daily Water Intake (liters)`.
Архитектуры: `3 → 10 → 1`, ReLU и Tanh. Классы: Poor=0, Good=1.

После обучения веса замораживаются. Добавляется один вход
`q = code(Gender) + code(Physical Activity Level) + code(Weather)`
с единичными весами для всех скрытых нейронов. Нулевой вход сохраняет исходные предсказания.
Коды подбираются программно на validation и экспортируются в Excel для ручного исследования.
Раздельно проверяются три признака, три пары и все три признака вместе.

После удаления 338 дубликатов осталось 29 662 объекта. Стратифицированное разбиение:
train 17 796, validation 5 933, test 5 933. Нормализация обучается только на train.
Эпоха и коды выбираются по validation; test не участвует в подборе.

| Модель | Ошибки теста до | После | Accuracy после |
|---|---:|---:|---:|
| ReLU | 3 | 4 | 99,9326% |
| Tanh | 7 | 0 | 100,0000% |

Общий результат не гарантирует улучшения для любой модели: у ReLU тестовое качество немного ухудшилось.
Ноль ошибок Tanh относится к данному разбиению. Малые коды в основном корректируют предактивации;
это не доказательство причинного влияния категорий.

Microsoft Excel пересчитал все 5 933 строки четырёх расчётных листов.
Меток, отличающихся от Python, нет; номера ошибочных строк также совпадают.

## Воспроизведение

```powershell
python -m pip install -r requirements-lab4.txt
python lab4_solution.py --output-dir lab4_reworked
```

После нового расчёта открыть Excel-книгу, выполнить полный пересчёт и сохранить её.
Либо при установленном Microsoft Excel выполнить `validate_lab4_excel.ps1`.

```powershell
python verify_lab4.py
python build_lab4_report.py
```

Для генерации PNG требуется локальный Chrome/совместимый браузер, доступный Kaleido.
Для сборки отчёта используется исходный шаблон `../Отчёт курсовая.docx`.
Основной расчёт: `lab4_recalculation.py`; формулы книги: `lab4_workbook.py`.
