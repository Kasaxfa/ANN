# Лабораторная работа № 4 — вариант 17

## Отчёт по курсовой работе

Работа посвящена влиянию цифрового кодирования категориальных признаков на качество бинарного классификатора. Вариант 17 выполнен на датасете `Daily_Water_Intake.csv`:

* целевая переменная: `Hydration Level`, `Poor=0`, `Good=1`;
* входы: `Age`, `Daily Water Intake (liters)`, `Gender`, `Physical Activity Level`, `Weather`;
* категории: `Gender` — 2 значения, `Physical Activity Level` и `Weather` — по 3 значения;
* архитектура: `Linear(5, 10) → ReLU → Linear(10, 1)`;
* разбиение: стратифицированные 80/20, `seed=42`.

Скрипт перебирает все `2! · 3! · 3! = 72` перестановки кодов категорий при фиксированных весах сети, а также отдельно исследует взаимовлияние пар категориальных признаков. В Excel-файле добавлены нулевой входной столбец и единичная строка матрицы весов первого слоя: это позволяет воспроизвести расчёт в расширенной форме без изменения прямого прохода.

По подготовленному расчёту baseline дал 757 ошибок и accuracy 87,3833%. Лучшая кодировка дала 751 ошибку и accuracy 87,4833%, то есть на 6 ошибок меньше. Для лучшей конфигурации `Gender`: `Female=1`, `Male=0`; остальные признаки сохранили порядок `Low/Moderate/High = 0/1/2` и `Cold/Normal/Hot = 0/1/2`.

Основной документ — `Отчёт по курсовой работе ЛР4.docx`. Таблица `water_variant17_lab4_work.xlsx` содержит листы `Summary`, `Raw_data`, `Input_augmented`, `Weights_augmented`, `check_baseline`, `Encoding_search`, `Interactions` и `Error_locations`.

## Запуск

```bash
pip install -r requirements.txt
python lab4_solution.py --data Daily_Water_Intake.csv --output-dir .
```

Скрипт повторно создаёт метрики, CSV-таблицы, workbook, графики и checkpoint `water_variant17_ReLU_10_lab4.pth`. Приложенные методические материалы и Excel-пример с медицинским датасетом использованы как описание формата задания; расчёт выполнен для датасета варианта 17.
