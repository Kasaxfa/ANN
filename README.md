# ANN — Лабораторная работа № 3

Вариант 17. Трёхмерная визуализация скрытого пространства нейронной сети на датасете **Daily Water Intake & Hydration Patterns Dataset**.

## Что выполнено

- целевой столбец `Hydration Level`: `Poor = 0`, `Good = 1`;
- после очистки выбраны четыре признака: `Age`, `Daily Water Intake (liters)`, `Physical Activity Level`, `Weather`;
- категориальные признаки закодированы порядковыми значениями и нормализованы по обучающей выборке;
- сеть `Linear(4, 3) → Tanh → Linear(3, 1)` обучена с `BCEWithLogitsLoss` и Adam;
- построены 3D-графики до функции активации, после `Tanh` и после `Tanh` с разделяющей плоскостью;
- коэффициенты выходного нейрона сохранены как коэффициенты плоскости в `metrics.json` и `water_variant17_Tanh_3_weights.xlsx`.

## Запуск

```bash
pip install -r requirements.txt
python lab3_solution.py
```

Скрипт создаёт или обновляет checkpoint `water_variant17_Tanh_3.pth`, workbook с весами, историю обучения, корреляционную матрицу и HTML-графики.

Открывать HTML можно локально в браузере. На сценах поддерживаются вращение мышью и масштабирование колёсиком. Цвета точек: красный — верный класс 0, зелёный — верный класс 1, фиолетовый — ошибка.

## Результат контрольного запуска

Для фиксированного seed 42, стратифицированного разбиения 80/20 и 60 эпох контрольный расчёт дал на тестовой части: accuracy **87.47%**, precision **91.70%**, recall **92.66%**, F1 **92.18%**. Матрица ошибок: `[[816, 401], [351, 4432]]`.

Файлы `heart.csv`, сцены про cirrhosis/stroke и notebook из приложенного примера в ветку не переносились: они не относятся к варианту 17 и заменены результатами на `Daily_Water_Intake.csv`.
