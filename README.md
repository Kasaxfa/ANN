# ANN — Лабораторная работа № 2

Вариант 17. Контрастирование нейронной сети на датасете **Daily Water Intake & Hydration Patterns Dataset**.

## Запуск

```bash
pip install -r requirements.txt
python lab2_solution.py
```

Скрипт обучает модель ReLU с 20 скрытыми нейронами и формирует анализ последовательного округления. Результаты находятся в `weights_ReLU_20_variant17.xlsx`, `contrast_metrics.csv` и `training_metrics_ReLU_20.csv`.

Workbook содержит демонстрационные строки обучающей выборки; полные агрегированные результаты воспроизводятся запуском скрипта.
